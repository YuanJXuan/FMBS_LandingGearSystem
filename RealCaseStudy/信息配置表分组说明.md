# 信息配置表的小标题

各模型的 `信息配置表.xlsx` 支持用绿色背景行定义列表小标题，名称不需要写入程序。

1. 在对应信息区内插入一行，将 A 列填为绿色的**实心填充**，在 A 列填写标题文字。
2. B～E 列留空；也可以像全机落震配置表一样合并 A～E 列。
3. 标题下方的参数归入该组，直到下一个绿色标题或下一个信息区。标题可以改名、增删、移动，也可以重名。
4. 保存 Excel 后，在界面点击“重新读取配置表”，名称和顺序会重新同步。

结构参数表、缓冲器参数信息、其他参数信息、结构参数信息和后处理曲线列表均使用这一规则。旧版“仿真参数化信息”中的分组显示在“其他参数信息”标签页。

界面的小标题沿用“轮胎与路面”列表的浅色加粗样式，始终展开，不能编辑或勾选。标题行不参与参数计数、模型写入或 Marker 示意图映射。没有绿色标题时仍显示原来的普通列表。

绿色支持 Excel 的 RGB 自定义颜色、主题绿色（含深浅变体）和索引绿色。建议复制已有绿色标题行来新增分组；条件格式产生的颜色不作为标题依据。已有黄色信息区名称及列名仍用于识别配置表结构，请保留。
